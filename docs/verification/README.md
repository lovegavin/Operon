# Verification

Evidence that still describes the line this tree ships. A page here is only
evidence if it states the tree it was run on, the date, and what was counted.

## The standard

[five-layer-test-standard.md](five-layer-test-standard.md) defines the layers and
is the only normative page in this directory. Everything else is a record of one
run against it.

## Operator quality

[operator-audit-2.1.0.md](operator-audit-2.1.0.md) is the audit of the operator
library at 2.1.0: declaration, contract, documentation and execution results per
operator, with the tree and the counts the run used.

## Coverage

[routes-5.x.md](routes-5.x.md) walks the route templates on the 5.x line —
what validates, what executes, and which dependencies each route needs.

## Science

[biological-evidence-4.0.0.md](biological-evidence-4.0.0.md) records the
biological checks behind the claim that the library's operators compute what they
say they compute.

[competitor-gap-matrix-v3.md](competitor-gap-matrix-v3.md) compares the product
against the tool categories it replaces, at the level of capability, not
marketing.

## What is not here

Older audits (7.0.x, 8.0.x, 4.x route walks, backend and interaction audits,
per-release application audits) were pruned with the rest of the historical
tree. They are in the git history and are not current claims; a page in this
directory has to earn its place by describing this line.

When you add one, state the commit, the date, the command you ran, and the count.
A number without those is not evidence.
