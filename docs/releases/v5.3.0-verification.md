## Scope limits

Automatic native canvas routes currently use one host. Multi-host/Slurm remain
experimental. Arbitrary unowned system executables, hidden dynamic resources,
GPU drivers and external services are not promised as self-contained exports.
System-R acquisition is implemented but the real R acceptance here used a private
Windows R installation; it is not a Linux system-R installation claim.

## RC3 installed follow-up: passed

The independent Windows testing machine downloaded and verified the exact RC3
ZIP and Setup, actually double-clicked Setup into a separate installation and
launched its new shortcut. Installation took 19.47 seconds; one Win32 error 5
during directory switching was retried automatically and installation succeeded.
The ordinary imported three-script/two-edge canvas passed HTTP preparation and
completed its pool attempt with exit 0, producing three CSVs.

First preparation took 387.58 seconds. The second preparation reused the same
environment generation and reached ready in approximately 1.86 seconds. Both
ordinary exports completed without a hand manifest (approximately 347 and 332
seconds). The generation and packages.json hashes matched; the source tar hash,
size and last-write time remained unchanged. Each distinct export still performs
a relocation probe, so environment reuse does not mean instant export.

The first export was moved to a directory containing spaces. Its own run.cmd ran
with developer PYTHONPATH/PYTHONHOME/application overrides removed and PATH
limited to Windows system directories. It completed in 60.14 seconds with exit 0.
The three CSVs matched Studio: source values 1..5, and two branches containing
2,4,6,8,10. The plan retained a 128 MB budget and automatic spill. This example's
factor=2 was frozen inside script code and its parameter JSON was empty; it is
not evidence of nonempty external-parameter freezing. Earlier focused parameter
tests remain separate evidence.

Old shortcuts were restored; 27/27 old baseline hashes matched and 11/11 old
profiles remained present. The RC3 installation/window were retained. Unchanged
tray full-exit, uninstall and Agent tests were not repeated; invalid input was
also not repeated in this interaction pass. The unchanged host's earlier exit
evidence remains separate. These are measured observations on this test machine,
not general performance guarantees or a claim that all operators were tested.
