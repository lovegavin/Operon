# Operon Studio 4.2.1

Released 2026-11-13. Operator library 8.0.9.

## Fixes

### Exported file artifacts download as the real file (NOL-02)

`GET /api/v1/jobs/{id}/artifacts/{artifact}/file` returned the cached
`files.json` manifest when no `?role=` was given, so MCP and browser downloads
received JSON instead of the exported table. The endpoint now resolves the
first declared export (`data` when present) and streams that file; an explicit
`?role=` still selects a named export, and unknown roles keep failing.

### Long job waits (NOL-04)

`operon_job(wait_seconds=...)` was limited to 30 seconds and raised outside
that range. The cap is now 120 seconds, and a wait that reaches its deadline
returns the job with `wait_timed_out: true` instead of an exception.

### Missing remote profile message (NOL-05)

When an SSH execution target cannot resolve its input environment, the error
now states that the server profile may be missing or disconnected and points to
`operon remote-status` / `operon remote-ensure`, instead of only echoing the
profile id.

### Gly→Ala interference in interface alanine scanning (OL-01)

`interface_alanine_scan` now marks Gly→Ala substitutions per row with `flag`,
`excluded_reason` and `excluded_from_ranking`, reports the count and details in
`quality.gly_to_ala_excluded` and `warnings`, and documents why those rows must
not be ranked: Glycine has no side chain, so replacing it introduces a methyl
group into the interface and produces non-physical ΔΔG outliers.

### Scientific limitations documentation (OL-02, OL-03)

`interface_alanine_scan` and `interface_mmgbsa_delta` now document that their
energies are single-point estimates without entropy, ensemble averaging or
calibration, that copy-to-copy and cross-version comparisons are not
quantitative, and that ranking interface hotspots requires replicates or an
ensemble protocol.

## Compatibility

- Application 4.2.1 requires operator library 8.0.6 or newer; 8.0.9 is bundled.
- Task folders from 4.2.0 keep working. Results remain under
  `<workspace>/<task>/results/<job-id>`.

## Validation

- Focused Python tests: `tests/test_file_artifacts.py`,
  `tests/test_execution_target.py`, artifact/table and library-bundle suites.
- Frontend: 177 tests across 30 files.
- Windows: install, startup, exported-file download over HTTP, and uninstall.
- Report items not fixed here: NOL-01 is a DSH sandbox denial outside Operon,
  and NOL-03 (20-row artifact table cap) did not reproduce on 4.2.0.
