# Operon Studio 4.0.2

Operon Studio 4.0.2 moves the default workspace of Setup-created installations into the installation root.

## Workspace

- A new or upgraded 4.0.2 installation records `workspace: "workspace"` in its
  installation marker and uses `<install root>/workspace` for workflows, jobs and
  the `.studio` data directory.
- Profile metadata, logs and browser state remain under
  `%USERPROFILE%\.operon\profiles\<id>`; only the working data moves.
- Installations created by earlier versions keep their existing profile workspace
  when the marker has no `workspace` field.
- Uninstall removes the program and runtime but preserves the install-root
  workspace and analysis results. The install root remains while the workspace is
  non-empty.

## Compatibility

- Application 4.0.2 targets the 8.0.1 built-in operator library.
- No protocol or SDK change; wire protocol 3, SDK 3.7.0.
