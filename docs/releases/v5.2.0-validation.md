  Portable relocation of these machine-specific versions is explicitly rejected;
  content-verified portable input bindings remain a separate path.
- New RunPlan artifacts support local original-file opening/saving. Remote full
  transfer and native specialist-viewer integration are not claimed for this path.

  library. Tests must record any independently installed library identity.
