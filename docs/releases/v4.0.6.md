# Operon Studio 4.0.6

Operon Studio 4.0.6 is a frontend correctness patch. The bundled library remains
8.0.2 (1,063 operators, 108 Readers, 1,171 descriptors and 79 routes), and the
protocol/SDK are unchanged.

## Fixes

- Artifact previews now use the dimensions returned by the server instead of
  label insertion order, so preview row labels and values stay aligned with the
  full artifact table.
- The canvas shows a stale-readiness warning when the graph changes after a
  check, instead of presenting an old `ready` result as current.
- A run is blocked before submission when multiple nodes use the same output
  name; the conflicting nodes are selected for correction.
- The inspector warns that disabling memory management reserves the whole pool,
  which can make a shared-pool submission wait or fail.

## Verification

- Frontend Vitest: 177 passed (30 files), including new duplicate-output and
  stale-readiness cases.
- Backend focused artifact tests: 32 passed.
- `tsc -b` and Vite production build passed.
- No additional Windows install/start test was run for this frontend-only
  patch; the 4.0.5 installer remains the Windows baseline.
