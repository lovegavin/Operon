# Operon Studio 4.1.2

## Cross-platform operator library verification

4.1.1 compared rebuilt provider wheels entry by entry, but it still included each
wheel's `RECORD` metadata. `RECORD` lists the other entries, and its row order
follows the filesystem's path collation: a case-insensitive Windows build and a
case-sensitive Linux build write different rows for names that differ only in
case. That made a library packaged on Windows fail verification on Linux and
vice versa, with `Library source does not match wheel`.

4.1.2 ignores `RECORD` when comparing wheels. Every real payload entry is still
hashed and compared, the declared file hashes are still verified, and the
application still requires an operator library of 8.0.6 or newer.

## Upgrade

Install 4.1.2 over 4.1.1. Workspaces, routes, results and the installed operator
library are preserved; the bundled library remains 8.0.6.
