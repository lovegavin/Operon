# Operon Studio 4.0.1

Operon Studio 4.0.1 fixes one-click server installation and library synchronization.

## Server install and update

- A server install now records the desktop build identity instead of recomputing a
  platform-specific identity from the extracted archive.
- Installing or updating a server always performs a full managed install. The
  incremental per-package upload path was removed from the UI.
- Server library checks compare the bundle/catalog identity, so provider-wheel
  and bundled-source hash domains no longer report every operator as changed.
- A changed library or zero-delta package list is now selectable for a full replacement.
- Dependency probes are deferred to execution time; a server install no longer
  reports zero passed dependencies.

## UI

- The server library panel is status-only and exposes a single
  "install / upgrade server" action.
- Deferred dependency readiness is rendered as "dependencies install on demand".

## Compatibility

- Application 4.0.1 targets the 8.0.1 built-in operator library.
- No protocol or SDK major change; wire protocol 3, SDK 3.7.0.
