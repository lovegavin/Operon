# Operon Studio 4.0.5

Operon Studio 4.0.5 is a small Windows Setup and route-import patch. The
bundled library remains 8.0.2 (1,063 operators, 108 Readers, 1,171 descriptors
and 79 routes), and the protocol/SDK are unchanged.

## Fix

After a successful installation, Setup updates the destination box to the
completed installation path. That refresh used to make the **强制重装** checkbox
visible again, even though the install had already finished. The checkbox is now
hidden whenever an installation result is present.

The option remains available while Setup is deciding whether to reinstall an
existing installation, and after a failed attempt that left the previous
installation in place. A failed installation never deletes the profile or
workspace.

## Route import guidance

When a route package cannot be imported, the operator library panel now tells
you to import the operator library of the same version first, then retry the
route package. This is a message-only frontend change; route data and library
files are not modified.

## Verification

This release was packaged without an additional Windows install/start test at
the user’s request; the change is limited to the visibility condition of the
force-reinstall checkbox. Prior 4.0.4 installer checks and the 4.0.3/8.0.2
application acceptance remain the reference.
