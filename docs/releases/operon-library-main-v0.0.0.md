# Operon Library main-v0.0.0

Base operator library bundle for Operon Studio 5.1.2 and newer.

- 7 packages, 1063 operators, 108 Readers, 1171 descriptors
- bundle_format 1, operator_protocol 3
- install as ``main`` / ``0.0.0`` (label ``main-v0.0.0``)

This is the same operator content as library 0.0.0; only the release identity
uses the ``<name>-v<version>`` scheme introduced in 5.1.2.
