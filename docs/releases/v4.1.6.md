# Operon Studio 4.1.6

- Remote shared pool status: the desktop now asks the connected server for the
  pool that actually owns its workspace.  The runtime status panel shows the
  remote pool version, PID, closing state, session count and jobs that are
  still queued, running or recovering, together with the server's application
  and library versions.  `operon_remote_status` reports the same summary.
- A server older than 4.1.6 answers `Unknown remote operation`; the panel then
  says the server is too old to report pool status instead of failing the
  connection.
- Observation never starts a remote pool.  A workspace without a running pool
  is reported as "shared pool is not running".
- Requires operator library 8.0.6 or newer; the built-in library is 8.0.6.
