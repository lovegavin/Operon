# Operon Studio 4.1.3

4.1.3 is a focused fix release for installation prompts and environment repair.

## Installation and uninstall

- The installation confirmation now states the exact selected directory, that it
  is used as the installation root without appending a child directory, and that
  uninstall removes everything in that root except `workspace`.
- The force-uninstall confirmation matches the same behaviour; it no longer
  claims that only installer-managed files are removed.

## Environment preparation

- Isolated operator environments are now prepared only by the dependency repair
  action: **Repair dependencies** in the operator library manager, the
  readiness checklist, or the MCP `operon_workflow_prepare_environment` tool.
- The separate "isolated environments" panel was removed; it duplicated the
  dependency repair entry point.
- Remote runs no longer prepare environments on the local machine after the
  server already performed the repair; local preparation is skipped when the
  graph targets an SSH server.

## Compatibility

- Built-in operator library: 8.0.6.
- Operator libraries older than 8.0.6 are rejected.
- Wire protocol v3 and SDK 3.7 are unchanged.

## Verification

- Backend focused tests: environment permissions, environment API/provisioner,
  dependency repair, library upgrade compatibility.
- Frontend: `tsc -b` clean and 177 tests passing.
- Installer: 0 warnings, 0 errors.
- Windows installation, startup and uninstall acceptance.
