# Operon Studio 4.0.4

This is an installer-only hotfix for 4.0.3. The application, runtime, operator
library (8.0.2), server package and wheels are unchanged apart from the version
string.

## Fix

Setup no longer crashes while checking a selected directory that contains files
but is not an Operon installation. The install check now treats that probe as
"not an existing installation" instead of throwing from ReadReceipt. Selecting
a valid existing Operon install still offers the normal reinstall / force
reinstall flow.

## Unchanged

- Operator library 8.0.2: 1,063 operators, 108 Readers, 1,171 descriptors,
  seven packages, 79 built-in routes.
- Protocol 3 / SDK 3.7.0.
- Workspace under the installation root; profile metadata and logs under the
  user profile.

No tests were rerun for this installer-only change. The 4.0.3 acceptance
results remain the reference for the application and library.

## Upgrade note

Setup creates a fresh profile for each installation. An older 4.0.x workspace
is not moved automatically; it remains under
%USERPROFILE%/.operon/profiles/<old-id>/workspace. Back it up, or copy it into
<install root>/workspace before relying on the new installation.
