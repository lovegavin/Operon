# Operon 3.1.2 — open-source notices and quick start

This packaging and documentation release includes the consistent Apache-2.0
license statement and current quick start in Windows Setup and the Linux server
bundle. The execution engine, scientific dependencies, SDK and factory operator
library retain the behavior delivered in 3.1.1.

- Remove the contradictory proprietary/copying restrictions from the README;
  the existing standard Apache-2.0 license applies, with contributor attribution
  preserved in NOTICE.
- Include LICENSE and NOTICE in Windows and Linux distributions and the
  application wheel. Third-party components retain their own notices/licenses.
- Add `docs/quickstart.md`, covering Windows, Linux, a synthetic first workflow,
  YAML, SSH and optional agent connection. Link it from the README, documentation
  index, Windows START_HERE and server bundle README.
- Correct older onboarding text about portable Full packages and opt-in pools.
  Shared-pool scheduling remains automatic, as in 3.1.1.

Download `Operon_Setup.exe` for Windows or `Operon-3.1.2-Server.zip` for Linux.
This release does not require an operator-library update. Existing published
3.1.1 artifacts are retained unchanged.

Validation is limited to the affected packaging/docs paths: targeted packaging
tests, wheel license metadata, version consistency, required file inclusion,
archive manifests, checksums and isolated Windows installation/startup. The
3.1.1 full engine/platform regression is not rerun for this documentation update.
See the release asset `VERIFICATION.md` for measured results.
