# Port contract inventory (application 5.8.2, library 1.2.1)

Frozen inventory behind the 5.8.2 port rule. The rule itself is recorded in
`HANDOVER-2026-11-25.md`: ports carry only `form` or `file_artifact`, and an
operator must not transport run data through a bare path parameter. Tool,
weights, resource and output paths stay as parameters and are annotated with a
role instead of being rejected.

Generated by `scripts/port_contract_inventory.py`; regenerate it rather than
editing by hand. Path roles are declared by name in that script, so an unknown
`*_path` name fails the run instead of silently joining the wrong role.
