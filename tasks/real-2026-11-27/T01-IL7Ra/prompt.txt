## 科学问题
针对 IL-7Rα（PDB 3DI3 链 B，残基 21–213）设计 58 aa α 螺旋 minibinder，
回答：RFdiffusion+ProteinMPNN 骨架的几何与序列复杂度如何决定候选的可折叠性；
单链 pLDDT 与复合物 ipTM 哪个才是可靠的筛选指标。

## 输入（已就位）
- `/public/home/lihj/Operon/workspace/task2/input/3DI3.cif`（RCSB 3DI3，mmCIF）
- `/public/home/lihj/Operon/workspace/task2/input/P16871.fasta`（UniProt IL-7Rα）
- 复用骨架：`/public/home/lihj/Operon/workspace/task2/v3/rf_design_{0..3}.pdb`
  （4 条已验证几何的 RFdiffusion 骨架：binder–靶标最小距离 4.2–4.5 Å，binder 58 aa）

## 路线（按顺序）
1. **读入**：`operon_operator_describe` 确认 `PdbReader` / `MmcifReader` / `proteinmpnn_design` /
   `colabfold_predict` / `export_results` / `protein_properties` / `protein_instability` 的参数。
2. **序列设计**：对 4 条骨架各跑 `proteinmpnn_design`：
   `device=cpu`、`chains=A`、`num_seq_per_target=2`、`sampling_temp` 分别 0.1 与 0.2、`seed` 7/14/21/28、`model_name=v_48_020`。
   期望 8 条 58 aa 序列。用 `export_results(format=fasta)` 导出。
3. **复杂度筛查**（本地 python 即可，数据量小）：单条序列中任一残基占比 >35%，或存在 ≥8 连续相同残基 → 判废，
   并在报告里列出判废原因（这是上轮失败的核心教训）。
4. **单链折叠**：对通过筛查的序列跑 `colabfold_predict`（`msa_mode=single_sequence`、`num_models=1`、
   `num_recycles=1`、`sequence_index` 按输入 FASTA 记录顺序选），记录 pLDDT（取 PDB 的 CA B-factor 均值）。
5. **复合物折叠（必做）**：把“binder 序列 + IL-7Rα 链 B 21–213 序列”写成两记录 FASTA，
   用 `colabfold_predict` 折成复合物，记录 ipTM、界面残基与界面面积（若算子无直接输出，用 PDB 自行计算
   8 Å 内重原子对数，并在报告里注明计算方法）。
6. **理化**：`protein_properties`（GRAVY、pI、分子量）与 `protein_instability`。
7. **排序**：候选表字段 = design / seq / 长度 / 最大残基占比 / pLDDT / ipTM / 界面残基 / GRAVY / instability / 判定。
   排序权重建议：ipTM 0.4、pLDDT 0.3、界面 0.2、instability 0.1（可在报告里说明）。
8. **交付**：把 FASTA、PDB、`candidates.csv`、图（pLDDT vs ipTM 散点、复杂度分布、Top 候选界面示意）
   写入仓库 `workspace/T01-IL7Ra/`；`results/` 放 CSV，`figures/` 放 PNG，`papers/` 放中文报告。
